# Disclaimer

**Experimental. Not advice. Testnet-10 only.**

oneword lives on Kaspa Testnet-10. tKAS has no value. oneword is not money, not a token, not an oracle, not a reward and not part of Kaspa core. There is no mainnet version and none is planned.

oneword is a plain Argent app. It is not a KCC. Argent (argent-lang/argent `9a9f4b10`) is not yet released and not audited. Silverscript v1.0.0 is released. The build uses the argent-lang/kcc20-reference checkout only as a pinned toolchain; oneword does not use KCC-20. Any of these can change, and if they do, this design may stop working.

Nothing here has had a security review. Treat the contract as a teaching sketch, not a vault for real money.

A oneword bond punishes one thing: signing two different statements for the same epoch. It does not make a statement true.

This repository holds no key, no seed and no wallet. Never paste a seed anywhere for this.
